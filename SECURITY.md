# Sécurité

## Signaler une faille

Ne publiez pas de faille dans une issue. Signalez-la en privé :
**[Security › Report a vulnerability](https://github.com/stakovicz/plume/security/advisories/new)**.

Indiquez la version de Plume, le système (macOS, Windows, Linux, navigateur) et les étapes pour reproduire.
Vous recevrez une réponse sous quelques jours ; le correctif est publié dans une nouvelle version, et la faille
décrite une fois la version disponible.

## Versions prises en charge

Seule la dernière version reçoit des correctifs : mettez Plume à jour (gestionnaire de paquets ou
[page des versions](https://github.com/stakovicz/plume/releases)).
