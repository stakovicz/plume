# Documentation de Plume

Plume est un éditeur vectoriel pour macOS, Windows et Linux, qui fonctionne aussi dans un navigateur.
Quatre parties, chacune pour un besoin différent.

| Vous voulez… | Lisez |
|---|---|
| **apprendre** Plume pas à pas, sans rien savoir | les [tutoriels](#tutoriels) |
| **réaliser** une tâche précise | les [guides pratiques](#guides-pratiques) |
| **vérifier** un raccourci, un réglage, un format | la [référence](#référence) |
| **comprendre** pourquoi Plume fonctionne ainsi | les [explications](#explications) |
