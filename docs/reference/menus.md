# Menus

Sur macOS et Linux, les menus sont ceux de l'application ; dans un navigateur, une barre de menus s'affiche
en haut de la fenêtre avec les mêmes commandes.

## Plume

À propos de Plume · Services · Masquer Plume · Masquer les autres · Tout afficher · Quitter Plume (⌘Q)

## Fichier

| Commande | Raccourci | Effet |
|---|---|---|
| Nouveau | ⌘N | document vide (propose d'enregistrer les modifications) |
| Ouvrir… | ⌘O | document `.json` ou image `.svg` |
| Ouvrir l'élément récent | | dix derniers fichiers (application de bureau) ; Effacer le menu |
| Enregistrer | ⌘S | dans le fichier en cours, ou demande où (navigateur : téléchargement) |
| Enregistrer sous… | ⇧⌘S | nouveau fichier `.json` |
| Exporter… | ⌘E | PDF, SVG, PNG, JPG (voir [Exporter](../guides/exporter.md)) |

## Édition

| Commande | Raccourci | Effet |
|---|---|---|
| Annuler / Rétablir | ⌘Z / ⇧⌘Z | |
| Couper / Copier / Coller | ⌘X / ⌘C / ⌘V | calques (ou texte dans un champ) ; colle aussi du SVG |
| Dupliquer | ⌘D | copie juste au-dessus, sans toucher au presse-papier |
| Tout sélectionner | ⌘A | calques visibles du niveau en cours (ou texte du champ) |
