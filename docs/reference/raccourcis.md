# Raccourcis de Plume

Sous Linux, ⌘ devient **Ctrl**, ⌥ devient **Alt** et ⇧ devient **Maj** ; la touche Retour est **Entrée**.
Les quelques raccourcis qui diffèrent davantage sont indiqués dans la colonne Linux.

## Fichiers et fenêtre

| Action | macOS | Linux |
|---|---|---|
| Nouveau / Ouvrir / Enregistrer / Enregistrer sous | ⌘N / ⌘O / ⌘S / ⇧⌘S | Ctrl+N / Ctrl+O / Ctrl+S / Ctrl+Maj+S |
| Exporter | ⌘E | Ctrl+E |
| Navigateur / Inspecteur | ⌥⌘1 / ⌥⌘2 | Ctrl+Alt+1 / Ctrl+Alt+2 |
| Réduire | ⌘M | menu Fenêtre › Réduire |
| Fermer la fenêtre / Quitter | ⌘W / ⌘Q | Ctrl+W / Ctrl+Q |

Dans la version web, le navigateur garde pour lui certains raccourcis (Ctrl+N, Ctrl+W, Ctrl+T sous Linux,
⌘N, ⌘W, ⌘Q sur macOS) : passez par la barre de menus de Plume.

## Outils

Actifs partout, sauf pendant la saisie dans un champ. Mêmes touches sur macOS et Linux.

| Outil | Touche |
|---|---|
| Sélection | Échap, ou Retour (Entrée) depuis un autre outil |
| Plan de travail | A |
| Plume | V |
| Crayon | P |
| Rectangle | R |
| Ovale | O |
| Texte | T |

## Souris et modificateurs sur le canevas

| Action | macOS | Linux |
|---|---|---|
| Ajouter / retirer de la sélection | ⇧-clic | Maj+clic |
| Sélection au lasso (⇧ : ajouter) | glisser depuis une zone vide | glisser depuis une zone vide (Maj : ajouter) |
| Entrer dans un groupe | double-clic | double-clic |
| Renommer un plan de travail | triple-clic sur son nom | triple-clic sur son nom |
| Ajouter un point à un tracé | clic sur un segment (édition de points) | idem |
| Point d'angle ↔ courbe | double-clic sur un point (édition de points) | idem |
| Fermer un tracé à la plume | clic sur le premier point ; Retour ou Échap pour le laisser ouvert | clic sur le premier point ; Entrée ou Échap |
| Courbe à la plume | glisser après le clic | idem |
| Texte sur une ligne / dans un cadre | clic / glisser (Échap pour terminer) | idem |
| Carré, cercle ; proportions ; angle par 15° | ⇧ en dessinant, redimensionnant, pivotant | Maj |
| Depuis le centre | ⌥ en dessinant ou redimensionnant | Alt |
| Poignée de Bézier indépendante | ⌥ en la glissant | Alt |
| Sans magnétisme (repères, grille) | ⌘ maintenu en glissant | Ctrl |

Sous Linux, certains environnements de bureau réservent Alt + glisser au déplacement des fenêtres : appuyez sur Alt
après avoir commencé à glisser, ou changez ce réglage du bureau.
